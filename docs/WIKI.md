> 面向玩家与整合包作者的条目式说明，内容对应当前版本 **1.7.2**。
> 想直接开玩看「三、快速上手」；想查具体物品看「六、插件详解」；想查配方看「七、配方详解」。

### 1.1 依赖关系

- **必须**：AnvilCraft 1.6.0 或更高（本模组直接用它的终端、存储网络、过滤组件、电网、充能配方、铁砧加工配方）。
- **必须**：NeoForge 21.1 或更高、Minecraft 1.21.1。
- **不冲突**：不使用 mixin，不覆盖本体类；与其他附属模组并存时不需要额外处理。

## 二、概述

铁砧工艺的终端（本地终端 / 潜影终端 / 超维终端）解决的是「随时随地存取物品」。
本模组在此基础上加了一套**可拆装的插件（升级模块）系统**：把功能做成一个个插件物品，
插进终端后，终端的存储就会按插件的能力自动干活 —— 收掉落物、做饭、喂食、用药水、搬流体、换工具、抓生物、
搬运经验、锻造、销毁多余物品、压缩、接电网充能，以及手动批量跑铁砧加工。

设计上的三条取向：

1. **可拆装**：插件是一枚物品，拆下来带走、装到另一台终端上，配置与状态都跟着物品走；
2. **贴本体**：能用铁砧工艺现有机制的就不另造一套（过滤组件、电网、充能配方、铁砧加工配方、存储网络全部复用）；
3. **不自动过头**：会消耗贵重材料的操作（锻造、铁砧加工）都做成**手动按钮触发**，避免玩家不在场时把家底吃掉。

## 三、快速上手

1. **做出安装台**：在冲压平台上放好铁砧与材料，用铁砧砸出**插件安装台**（4 铁块 + 1 铁砧）。
2. **做出插件**：插件同样只有铁砧工艺配方（冲压为主，个别走时移或充电器充能），工作台做不出来。
3. **准备存储**：本地终端需要 32 格内有一个大型板条箱；潜影终端需要身上带潜影集装箱。
4. **装插件**：右键安装台 → 左侧槽放终端 → 下方 3×3 放插件 → 点「**安装全部**」。
5. **把终端拿回背包**：台面上的终端不会工作（插件只驱动玩家身上的终端）。
6. **调插件**：在终端界面里点「**插件**」按钮或按 **K**；列表页选中插件 →「设置」改配置，「执行」跑配方。

## 四、核心概念

### 4.1 终端

| 终端 | 连接对象 |
|---|---|
| 本地终端 | 玩家 32 格以内最近的大型板条箱 |
| 潜影终端 | 身上第一个潜影集装箱；没有则 64 格以内最近的一个 |
| 超维终端 | 已绑定的全局存储（超维存储站） |

插件只驱动**玩家身上**（背包、主手、副手）的终端。终端放在安装台里、或掉在地上时，插件不工作。

### 4.2 插件

- 插件是物品，最多同时装 **5 个**（`maxPluginsPerTerminal` 可调，上限 9）；
- 插件的**设置与状态保存在插件物品自身的数据组件**里：拆下带走、换终端依然有效；
- 列表里可以单独**停用**某个插件（不拆下但暂时不生效）；
- 插件的贴图是一套统一风格的「模块板」：铁灰板身 + 黄铜条 + 引脚 + 各自的图案。

### 4.3 插件安装台

- 一个方块，右键打开界面；界面尺寸 176×220，分三块：**终端槽（左）**、**3×3 暂存槽（下）**、**操作按钮（右）**；
- 三个按钮：**安装全部**、**全部拆卸**、**调节插件**；
- 暂存槽**只暂存**，放进去不会自动安装 —— 必须点「安装全部」，这样每一步都看得见；
- 拆下来的插件会回到暂存槽；暂存槽满了就留在终端上；
- 台面上的终端**不工作**，装完记得拿回背包。

### 4.4 插件面板

叠加在终端界面之上的浮窗（不会关闭你已经打开的界面），可拖动。

- **打开**：终端界面里的「插件」按钮，或按 **K**；安装台界面点「调节插件」；
- **拖动**：按住顶部「==」按钮拖动；位置记在 `config/anvilcraft_terminal_plugins_panel.txt`，下次进游戏仍然生效；
- **列表页**：图标 + 名称 + 启用状态（最多显示 5 行，更多显示「+N」）；底部按钮为 启用/停用、↑、↓、拆下、设置、执行（执行按钮只有会跑配方的插件才有）；
- **设置页**：只放配置项，每个设置就是一个按钮，**按钮上直接写着当前值**，点一下循环切换，鼠标悬停有说明；
- **执行页**：配方相关操作（加工方式 / 批次 / 输入槽 / 输出槽 / 开始按钮）；
- 操作失败（比如终端不在身上）会在快捷栏上方提示。

### 4.5 存储

铁砧工艺的存储是「**按类型计数、数量无限**」的模型：每种物品占一个类型槽，同一种物品的数量没有上限。
所以本模组不提供「扩容类」插件（容量、堆叠上限）—— 那些在本体的模型里没有意义。

## 五、界面与操作

### 5.1 手持快速配置

不用打开面板也能改：手持插件**右键**切换主档位、**潜行 + 右键**切换副档位，聊天栏会提示新值。

| 插件 | 右键（主） | 潜行右键（副） |
|---|---|---|
| 过滤 | 白名单 ↔ 黑名单 | 是否比对组件 |
| 磁吸 / 拾取 | 半径 3 → 5 → 8 → 12 → 16 | 磁吸+拾取 → 仅磁吸 → 仅拾取 |
| 自动熔炼 · 烹饪 | 熔炼 → 高炉 → 烟熏 → 营火 | 是否需要燃料 |
| 自动喂食 | 饥饿阈值 2 → 4 → 6 → 8 → 12 → 16 | 是否允许负面效果食物 |
| 炼金 | 作用范围 仅自己 → 玩家 → 生物 → 全部 | 是否要求匹配效果等级 |
| 流体接口 | 关闭 → 抽进缓冲 → 灌进容器 | 每周期批数 1 → 2 → 4 → 8 → 16 |
| 工具切换 | 耐久阈值 5% → 10% → 25% → 50% | 仅主手 ↔ 整个快捷栏 |
| 生物捕捉 | 搜索半径 4 → 8 → 12 → 16 | 是否连敌对 / 中立生物一起抓 |
| 经验泵 | 关闭 → 存入 → 取出 | 每周期宝石数 1 → 2 → 4 → 8 |
| 锻造 | 每周期锻造次数 1 → 2 → 4 → 8 → 16 | —— |
| 销毁 | 保留组数 0 → 1 → 2 → 4 → 8 → 16 → 64 | —— |
| 压缩 | 每周期处理组数 1 → 2 → 4 → 8 → 16 | —— |
| 充能 | 申请功率 4 → 16 → 64 → 256 kW | 是否执行充能配方 |
| 铁砧加工 | 加工方式：冲压 → 粉碎 → 压缩 → 分解 → 过筛 → 超加热 → 时移 → 中子辐照 | 本次加工次数 1 → 8 → 64 |

### 5.2 过滤表怎么用

设置页里的过滤表是 18 格（6×3）：**左键放入光标上拿着的物品、右键清空**。

| 插件 | 过滤表留空时 |
|---|---|
| 销毁、压缩、锻造 | **什么都不做**（必须显式列出要处理的物品，防止误删误压） |
| 流体接口、工具切换 | **对全部目标生效** |
| 铁砧加工 | **不限制**（它由按钮触发，不会自己动手） |
| 生物捕捉、经验泵 | 不使用过滤表 |

### 5.3 输入槽与输出槽

会执行配方的四个插件（锻造、充能、压缩、铁砧加工）在执行页有槽位：

- **输入槽**：左键放入光标上的物品、右键清空。留空＝自己挑，填了＝只处理这一种；
- **输出槽**：只读，显示最近一次成功加工的产物；
- **锻造**：三个输入槽 —— 工具（基底）/ 金属（附加物）/ 模板。

## 六、插件详解

### 6.1 过滤插件

- **作用**：决定哪些物品允许进入终端连接的存储；本附属所有自动入库（磁吸拾取、烹饪产物、炼金空瓶、经验宝石等）都会先经过它。
- **设置**：模式（白名单 / 黑名单）、是否比对组件、18 格过滤表。
- **说明**：过滤组件复用铁砧工艺本体的实现，支持命名牌写 `#tag` 做标签过滤。
- **限制**：只约束本附属的自动入库；玩家在终端界面里手动存进去的物品不受它限制。

### 6.2 磁吸 / 拾取插件

- **作用**：把附近的掉落物直接收进存储。
- **设置**：半径 3/5/8/12/16（默认 5）；模式（磁吸 + 拾取 / 仅磁吸 / 仅拾取）；是否连经验球等其它实体一起收。
- **说明**：「磁吸」是把掉落物拉向玩家，「拾取」是直接进存储；不需要拉近只想入库时用「仅拾取」。

### 6.3 自动熔炼 · 烹饪插件

- **作用**：把存储里的原料按烹饪配方加工，产物回到存储。
- **设置**：配方类型（熔炼 / 高炉 / 烟熏 / 营火）、是否需要燃料。
- **说明**：使用原版烹饪配方；单次处理量由配置 `autoCookingBatchSize`（默认 8）控制；不开燃料就不消耗燃料。

### 6.4 自动喂食插件

- **作用**：饥饿时自动从存储取食物进食。
- **设置**：饥饿阈值 2/4/6/8/12/16（默认 6）、是否允许负面效果食物、是否保留饱和度。
- **说明**：碗、瓶等容器会放回存储，不会消失。

### 6.5 炼金插件

- **作用**：满足条件时自动使用存储里的药水。
- **设置**：4 个条目，每条 = 药水过滤槽 + 触发条件（从不 / 总是 / 水下 / 着火 / 下落 / 疾跑 / 受伤低于 X / 有负面效果）+ 阈值；作用范围（仅自己 / 玩家 / 生物 / 全部）；作用半径 1~8；是否要求等级匹配。
- **说明**：普通药水直接饮用，喷溅 / 滞留药水就地投掷，不祥之瓶照常使用；空瓶放回存储。

### 6.6 流体接口插件

- **作用**：在存储里的容器和插件自带的**储液缓冲**之间搬运流体 —— 流体始终以桶 / 瓶这类容器物品的形式进出存储。
- **设置**：工作模式（关闭 / 抽进缓冲 / 灌进容器）、每周期批数 1~16、缓冲容量 1~64 桶（默认 8 桶）、过滤表（允许哪些容器参与）。
- **说明**：桶、玻璃瓶、水瓶、蜜瓶、不祥之瓶等特例由本体逻辑处理；取容器失败或灌装失败时会把容器原样放回，不会丢物品。

### 6.7 工具切换插件

- **作用**：手持工具快坏掉时，自动从存储换一把同种、剩余耐久更多的工具。
- **设置**：耐久阈值 5%/10%/25%/50%（默认 10%）、作用范围（仅主手 / 整个快捷栏）、旧工具是否放回存储。
- **说明**：替换品的剩余耐久必须**严格大于**当前工具，所以不会来回换；只换同一种物品，不会帮你把镐换成斧。

### 6.8 生物捕捉插件

- **作用**：把存储里的**空树脂块**变成「装着生物的树脂块」。
- **设置**：搜索半径 4/8/12/16（默认 8）、是否连敌对 / 中立生物一起尝试。
- **说明**：捕捉规则与手动捕捉一致 —— 体积太大的抓不了，敌对 / 中立生物需要先被施加虚弱；抓成功才消耗树脂块，失败原样放回。

### 6.9 经验泵插件

- **作用**：在玩家经验与存储里的**经验宝石**（1 颗 = 50 点经验）之间搬运经验。
- **设置**：模式（关闭 / 存入 / 取出）、存入阈值等级（默认 30）、取出保留等级（默认 5）、每周期宝石数 1~8。
- **说明**：存入时等级高于阈值才动手，取出时等级低于保留值才补；如果宝石被过滤插件拦下，扣掉的经验会原样退回。

### 6.10 锻造插件

- **作用**：用存储里的**工具 / 金属 / 模板**完成锻造台配方（下界合金升级、盔甲纹饰等）。
- **设置**：执行页三个槽（工具 / 金属 / 模板）、批次 1~8、开始锻造按钮；设置页是过滤表（允许当基底的物品）。
- **说明**：**模板不会被消耗**，只消耗工具与金属；槽位留空时自动从存储里找满足配方的物品；三件材料缺任何一件都不会动手。

### 6.11 销毁插件

- **作用**：存储里匹配过滤的物品只保留指定组数，多余部分销毁。
- **设置**：保留组数 0/1/2/4/8/16/64；过滤表（必填）。
- **说明**：留空过滤表时完全不动作，这是为了防止建好插件后立刻把家底清空。

### 6.12 压缩插件

- **作用**：把存储里 9 个同类物品压成 1 个（例如 9 铁粒 → 铁锭、9 铁锭 → 铁块）。
- **设置**：每周期处理组数 1/2/4/8/16；过滤表（必填）；执行页有输入 / 输出槽（留空输入槽表示按过滤表自己挑）。
- **说明**：用原版 3×3 合成配方判定，所以只处理「本来就能 3×3 合成」的物品。

### 6.13 充能插件

- **作用**：把玩家接入铁砧工艺的**电网**，做两件事 —— 跑本体的**充能配方**、给身上的 **FE 物品**充电。
- **设置**：申请功率 4/16/64/256 kW（默认 16）、是否执行充能配方、是否给 FE 物品充电。
- **说明**：
  - 取电方式与本体的用电器一致：站在输电杆覆盖范围内即可，电网过载时自动停机；
  - 电转 FE 的速率读取游戏配置（默认 1 kW = 100 FE/t），按本体的注入节奏批量结算；
  - 充能配方需要「申请功率 ≥ 配方功率」才会开始推进，进度存在插件物品里，拆下来也不会丢；
  - 插件被拆下 / 停用 / 玩家下线时，占用的电网功率会被释放。

### 6.14 铁砧加工插件

- **作用**：把本体的**铁砧加工**搬进界面里**手动批量**执行，省去搭结构、搬铁砧的过程。
- **支持**：冲压 / 粉碎 / 压缩 / 分解 / 过筛 / 超加热 / 时移 / 中子辐照。
- **设置**：加工方式、本次加工次数 1/8/64、过滤表（可选）、输入槽。
- **说明**：
  - **只在按下「开始加工」时执行**，不会自动跑；
  - 配方判定与产出使用本体数据，概率产出照常掷骰；
  - 需要炼药锅流水的配方（固液反应、快速烹饪）不收录；
  - 材料从存储取、产物回存储；取出过程中任何一步失败都会把已取出的原样放回。

## 七、配方详解

本模组的物品**只有铁砧工艺的做法**，工作台做不出来。

### 7.1 冲压（13 条）

冲压需要搭「铁砧 + 冲压平台」的结构，把材料放在平台上让铁砧砸下去。

| 产物 | 材料 |
|---|---|
| 过滤插件 | 电路板 + 2 铁锭 |
| 磁吸 / 拾取插件 | 电路板 + 2 磁铁锭 |
| 自动熔炼 · 烹饪插件 | 电路板 + 加热器 |
| 自动喂食插件 | 电路板 + 2 金胡萝卜 |
| 炼金插件 | 电路板 + 酿造台 |
| 销毁插件 | 电路板 + 虚空物质 |
| 压缩插件 | 电路板 + 2 活塞 |
| 流体接口插件 | 电路板 + 2 玻璃 |
| 工具切换插件 | 电路板 + 钻石镐 |
| 生物捕捉插件 | 电路板 + 树脂块 |
| 经验泵插件 | 电路板 + 2 经验宝石 |
| 锻造插件 | 电路板 + 皇家钢锭 |
| 插件安装台 | 4 铁块 + 1 铁砧 |

### 7.2 时移（1 条）

| 产物 | 材料 |
|---|---|
| 铁砧加工插件 | 1 个铁砧 |

### 7.3 充电器的充能配方（1 条）

| 产物 | 材料 | 参数 |
|---|---|---|
| 充能插件 | 1 个过滤插件 | 16 kW × 200 tick |

这条配方正好可以用充能插件自己来跑：把过滤插件放进终端存储，装上充能插件并站在电网里，它就会自己把过滤插件充成充能插件。

### 7.4 关于配方开关

这些配方都带条件 `anvilcraft_terminal_plugins:recipes_enabled`，对应配置项 `enableAnvilCraftRecipes`。
关掉后配方在数据包加载阶段就不会被载入 —— 注意工作台配方并不存在，所以关掉等于本模组物品没有任何配方（这个开关主要留给整合包自行改写配方）。

## 八、配置文件

位置：`config/anvilcraft_terminal_plugins-common.toml`（首次进游戏自动生成）。

| 配置项 | 默认值 | 取值范围 | 作用 |
|---|---|---|---|
| `maxPluginsPerTerminal` | 5 | 1 ~ 9 | 单台终端最多能装几个插件 |
| `pluginTickInterval` | 10 | 1 ~ 100 | 插件行为检测间隔（tick）。调小反应更快、开销更大 |
| `magnetDefaultRange` | 5 | 1 ~ 16 | 磁吸 / 拾取插件的默认半径（新建的插件用这个值） |
| `autoCookingBatchSize` | 8 | 1 ~ 64 | 自动烹饪单次处理的最大物品数 |
| `enableAnvilCraftRecipes` | true | true/false | 是否启用本模组物品的铁砧工艺配方 |
| `debugLogging` | false | true/false | 在日志里打印插件派发信息，排查「插件不生效」时打开 |

## 九、机制与数值

### 9.1 插件的工作节拍

服务端每隔 `pluginTickInterval`（默认 10 tick）扫描一次玩家身上的终端，再按各插件自己的周期决定是否执行。
因此实际节拍是「派发间隔」与「插件周期」的公倍数：

| 插件 | 声明的周期 | 实际大约多久动一次 |
|---|---|---|
| 磁吸 / 拾取、炼金 | 5 tick | 每次派发（约 0.5 秒） |
| 自动烹饪、工具切换、充能 | 10 tick | 约 0.5 秒 |
| 过滤、自动喂食、流体接口、生物捕捉、经验泵 | 20 tick | 约 1 秒 |
| 销毁、压缩、锻造 | 40 tick | 约 2 秒 |
| 铁砧加工 | 无（手动） | 只在按「开始加工」时执行 |

### 9.2 插件的状态存在哪

所有设置（半径、阈值、过滤表、充能进度、输入输出槽……）都写在**插件物品的数据组件**里。
因此：拆下插件带走设置；把插件放到另一台终端上，设置照旧；用复制物品的手段复制插件，设置也会被一起复制。

### 9.3 自动入库的统一入口

所有自动入库（磁吸拾取、烹饪产物、炼金空瓶、压缩产物、充能产物、经验宝石等）都会先经过**过滤插件**，
再写进存储；被拦下的物品不会进存储（经验泵在这种情况下会把经验退回玩家）。

### 9.4 充能的取电细节

- 插件把「申请功率」登记到玩家身上，与本体的用电器（例如飘升机背包）共用同一套电网判定；
- 电网发电功率不足（过载）时判定为「没有电」，插件本周期什么都不做；
- 电转 FE 的速率取自本体配置：默认 1 kW 对应 100 FE/t，注入按本体的节奏批量结算；
- 充能配方需要「申请功率 ≥ 配方功率」，所以 4 kW 档跑不动 70 kW 的电容器配方，需要调高档位。

## 十、兼容性与已知限制

1. **不使用 mixin**，不修改铁砧工艺本体代码；插件面板以叠加层形式绘制在终端界面上。
2. 过滤插件只约束本附属的自动入库；玩家手动存进终端的物品不受它限制。
3. 自动烹饪使用原版烹饪配方；本体的多方块「超级加热」等世界中配方不适合在存储里套用。
4. 炼金插件使用存储里现成的药水，喷溅药水就地投掷，不做弹道瞄准。
5. 铁砧加工只收录纯物品进出的加工方式；方块类加工（方块粉碎、压合、涂抹、压榨）作用对象是方块，不收录。
6. 压缩插件用原版 3×3 合成配方判定，与本体「物品压缩」的配方范围可能不完全一致。
7. 插件只驱动玩家身上的终端；放在安装台里的终端不会工作。

## 十一、常见问题

**Q：插件装了但没反应。**
A：按顺序检查 —— ① 终端在身上（不是放在安装台里）；② 列表里插件是「启用」状态；③ 存储连得上（本地终端 32 格内有大型板条箱）；④ 插件自身的条件是否满足（比如喂食要饥饿值够低、炼金要存储里有对应药水）。
把配置 `debugLogging` 改成 `true`，日志里会出现 `plugin-dispatch`（每次派发）与 `plugin-run`（某个插件真的执行了）两种行，看缺哪一种就知道卡在哪一步。

**Q：面板打不开 / 按钮点不到。**
A：面板只在终端界面里打开（或在安装台界面点「调节插件」）。如果和别的界面元素重叠，按住顶部「==」把它拖走，位置会被记住。

**Q：安装台放进去的东西去哪了？**
A：放进去不会自动安装，它们还在暂存槽里；点「安装全部」才会装到终端上，装完插件只有「已安装插件」那一行的图标，本体不在暂存槽里了（它已经在终端上）。

**Q：拆卸后插件去哪了？**
A：回到安装台的暂存槽；如果暂存槽满了，插件会继续留在终端上。

**Q：锻造为什么一定要放模板？会被吃掉吗？**
A：模板决定能锻造出什么，不可少；但**不会被消耗**，放一次可以一直用。

**Q：铁砧加工按了「开始加工」没反应。**
A：确认存储里真的有该配方需要的材料；过滤表留空表示不限制，填了内容就只处理表里的物品；输入槽若指定了物品，也只会处理那一种。

**Q：充能插件不工作。**
A：需要站在电网覆盖范围内（由输电杆提供）且电网未过载；另外充能配方有功率门槛，配方要求高于申请功率时不会启动。

**Q：能不能把本模组放进整合包？**
A：可以，LGPL-3.0-or-later 允许；再分发修改版时保留同样的许可与版权声明即可。

## English Summary

**AnvilCraft-TerminalPlugins** (`anvilcraft_terminal_plugins`) is an addon for **AnvilCraft** on Minecraft 1.21.1 /
NeoForge that adds a **plugin (upgrade module) system** to the Local, Shulker and Hyperdimension terminals.

### What it adds

- **Plugin Station** — a block with one terminal slot, nine staging slots (3x3) and three buttons: Install all,
  Uninstall all and Open panel. Staging never installs by itself, and a terminal left in the station does not work.
- **Plugin panel** — an overlay drawn on the terminal screen (button or **K**), draggable, position remembered in
  `config/anvilcraft_terminal_plugins_panel.txt`. The list page offers enable/disable, reorder, remove, settings and run.
- **14 plugins** —
  1. **Filter** — decides which items may enter the storage (whitelist/blacklist, component matching, `#tag` filters);
     every automatic insert of this addon goes through it;
  2. **Magnet / Pickup** — pulls drops in from a configurable radius (3/5/8/12/16) and stores them;
  3. **Auto Cooking** — smelts/cooks stored ingredients (furnace, blast furnace, smoker, campfire; optional fuel);
  4. **Feeding** — feeds you from the storage, containers go back;
  5. **Alchemy** — uses stored potions when a condition is met (underwater, on fire, falling, sprinting, hurt below X%,
     having a debuff, ...); drinks normal potions, throws splash ones, puts empty bottles back;
  6. **Fluid** — moves fluids between containers in the storage and the plugin's own buffer (1-64 buckets);
  7. **Tool Swap** — replaces a nearly broken tool with a less worn copy of the same item;
  8. **Mob Catcher** — catches nearby mobs into empty resin blocks (same rules as catching by hand);
  9. **XP Pump** — moves experience between you and exp gems in the storage (1 gem = 50 XP);
  10. **Smithing** — forges with a tool, a metal and a template; **the template is kept**;
  11. **Void** — destroys everything of a filtered type beyond the kept amount;
  12. **Compacting** — turns 9 identical items into 1 using vanilla 3x3 recipes;
  13. **Charging** — draws power from an AnvilCraft **grid**, runs charging recipes and charges the FE items you carry;
  14. **Anvil Process** — runs the mod's anvil processing methods (stamping, crushing, compressing, unpacking, sifting,
      super heating, time warp, neutron irradiation) by hand, in batches.
- **Filters** — plug-ins that destroy or consume (void, compacting, smithing) do nothing while the filter table is empty;
  utility plugins (fluid, tool swap) treat an empty table as "everything"; the anvil processing plugin is manual and is
  therefore unrestricted when empty.
- **Run page** — the four recipe plugins have a separate run page with input/output slots; smithing has three input slots
  (tool / metal / template).
- **Recipes** — AnvilCraft-style only (13 x stamping, 1 x time warp, 1 x charger charging); there are no crafting table
  recipes, and every recipe uses different materials.

### Config

`config/anvilcraft_terminal_plugins-common.toml`: `maxPluginsPerTerminal` (5), `pluginTickInterval` (10),
`magnetDefaultRange` (5), `autoCookingBatchSize` (8), `enableAnvilCraftRecipes` (true), `debugLogging` (false).

### Troubleshooting

Set `debugLogging = true` and look for `plugin-dispatch` / `plugin-run` lines in `logs/latest.log` to see whether the
terminal is found and which plugin actually runs.

- no mixins, nothing in AnvilCraft is patched;
- **LGPL-3.0-or-later** — free to use, modify and include in modpacks.
