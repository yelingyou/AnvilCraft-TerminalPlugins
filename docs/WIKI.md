## 二、快速上手

1. **做安装台**：用冲压（铁砧落在冲压平台上）把 4 个铁块 + 1 个铁砧压成**插件安装台**。
2. **做插件**：插件同样只用铁砧工艺的做法获得（冲压 / 时移 / 充电器充能），没有工作台配方。
3. **装插件**：右键安装台 → 左侧槽放**终端**、下方 3×3 放**插件** → 点「**安装全部**」。
4. **拿回终端**：把终端从安装台拿走放回背包（台面上的终端不会工作）。
5. **调插件**：在终端界面里点「**插件**」按钮或按 **K** 打开面板；每个插件有「**设置**」页，会执行配方的插件还有「**执行**」页。

## 三、核心概念

### 3.1 终端

指铁砧工艺本体的三种终端：**本地终端**（自动连接 32 格内最近的存储站）、**潜影终端**（连接身上的潜影集装箱，没有则连 64 格内最近的）、**超维终端**（连接绑定的全局存储）。
插件只驱动**玩家身上的终端**（背包、主手或副手），放在安装台里的终端不生效。

### 3.2 插件

插件是一枚可以装上、拆下的物品，最多同时装 **5** 个（可在配置里改）。
插件的**全部设置与状态都存在插件物品自身的数据组件里**：拆下来带走、装到另一台终端上依然有效。

### 3.3 插件安装台

装 / 卸插件的唯一入口。槽位分三块：左侧 1 格放终端、下方 3×3 是**暂存槽**、右侧三个按钮分别是「安装全部」「全部拆卸」「调节插件」。
暂存槽只是暂存 —— 放进去**不会自动安装**，需要点按钮。

### 3.4 插件面板

叠加在终端界面上的一层浮窗（不会关掉你已经打开的界面），可以拖动，位置记在 `config/anvilcraft_terminal_plugins_panel.txt`。
面板分三页：**列表页**（插件图标、名称、启用状态、拆下 / 排序 / 启用按钮）→ **设置页**（配置项）→ **执行页**（会执行配方的插件才有）。

### 3.5 存储

插件作用于**终端当前连接的存储**。铁砧工艺的存储是「按类型计数、数量无限」的模型：每个物品类型占一个槽位，同一类型的数量没有上限。

## 四、物品一览

### 4.1 插件安装台

一个方块。右键打开界面，用来把插件装到终端上或从终端上取下。

### 4.2 插件（14 种）

| 插件 | 作用 | 触发方式 | 主要设置 |
|---|---|---|---|
| **过滤** | 决定哪些物品允许进入终端连接的存储 | 被动（所有自动入库都会经过它） | 白名单 / 黑名单、是否比对组件；18 格过滤表 |
| **磁吸 / 拾取** | 把附近的掉落物收进存储 | 自动（每 10 tick 检查） | 半径 3/5/8/12/16；磁吸 + 拾取 / 仅磁吸 / 仅拾取 |
| **自动熔炼 · 烹饪** | 在存储里加工原料 | 自动（每 40 tick 一批） | 配方：熔炼 / 高炉 / 烟熏 / 营火；是否消耗燃料 |
| **自动喂食** | 饥饿时自动进食 | 自动（饥饿值达到阈值时） | 阈值 2/4/6/8/12/16；是否允许负面效果食物 |
| **炼金** | 满足条件时自动使用存储里的药水 | 自动（条件触发） | 4 个条目（药水 + 触发条件 + 阈值）；作用范围；是否要求等级匹配 |
| **流体接口** | 在存储里的容器和插件自带储液缓冲之间搬运流体 | 自动（每周期） | 工作模式：关闭 / 抽进缓冲 / 灌进容器；批数；缓冲容量（1~64 桶） |
| **工具切换** | 手持工具快坏掉时换成存储里更好的同种工具 | 自动（每 10 tick） | 耐久阈值 5%/10%/25%/50%；仅主手 / 整个快捷栏；旧工具是否放回存储 |
| **生物捕捉** | 用存储里的空树脂块捕捉附近生物 | 自动（每 20 tick） | 搜索半径 4/8/12/16；是否连敌对 / 中立生物一起尝试 |
| **经验泵** | 在玩家经验与存储里的经验宝石之间搬运经验（1 颗 = 50 点） | 自动（每周期） | 模式：关闭 / 存入 / 取出；存入阈值等级；取出保留等级；每周期宝石数 |
| **锻造** | 用存储里的工具 / 金属 / 模板完成锻造台配方 | 手动（执行页按「开始锻造」） | 批次；执行页三个槽：工具 / 金属 / 模板；过滤表 |
| **销毁** | 存储里匹配过滤的物品只保留指定组数 | 自动（每 40 tick） | 保留组数 0/1/2/4/8/16/64；过滤表 |
| **压缩** | 把存储里 9 个同类物品压成 1 个（原版 3×3 配方） | 自动（每 40 tick） | 每周期组数 1/2/4/8/16；过滤表 |
| **充能** | 接入电网：跑充能配方、给身上的 FE 物品充电 | 自动（站在电网里时） | 申请功率 4/16/64/256 kW；是否执行充能配方；是否给 FE 物品充电 |
| **铁砧加工** | 手动批量执行本体的铁砧加工（冲压 / 粉碎 / 压缩 / 分解 / 过筛 / 超加热 / 时移 / 中子辐照） | 手动（执行页按「开始加工」） | 加工方式；本次次数 1/8/64；过滤表（可选）；输入槽 |

## 五、机制说明

### 5.1 过滤表

设置页里的 18 格过滤表决定「允许处理哪些物品」：左键放入光标上的物品、右键清空。

- 销毁 / 压缩 / 锻造：**留空 = 什么都不做**（避免误删误压，必须显式列出要处理的物品）；
- 流体接口 / 工具切换：**留空 = 对全部目标生效**；
- 铁砧加工由按钮触发，**留空 = 不限制**，填了才按表筛；
- 生物捕捉与经验泵不使用过滤表。

### 5.2 执行页与输入 / 输出槽

锻造、充能、压缩、铁砧加工这四种「会执行配方」的插件，在列表行上除了「设置」还有一个「**执行**」入口，进去后：

- **输入槽**：左键放入光标上的物品，右键清空。留空表示「自己挑」，填了就只处理这一种；
- **输出槽**：只读，显示最近一次成功加工的产物；
- 锻造执行页有三个槽：**工具（基底）/ 金属（附加物）/ 模板**，对应本体皇家锻造台的三个格子；
- **模板不会被消耗**，只消耗工具与金属。

### 5.3 工作节拍

插件行为由服务端按固定节拍驱动，默认每 **10 tick**（0.5 秒）扫描一次玩家身上的终端，各插件再按自己的周期决定是否执行。
这个间隔可以在配置里调整。

### 5.4 充能与电网

充能插件把玩家当作一个「用电器」接入铁砧工艺的无线电网：站在输电杆覆盖范围内即可取电。
电网发电功率不够（过载）时插件自动停机，不会凭空造电。电转 FE 的换算比例读取游戏配置。

## 七、配置文件

位置：`config/anvilcraft_terminal_plugins-common.toml`。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `maxPluginsPerTerminal` | 5 | 单台终端最多安装的插件数量 |
| `pluginTickInterval` | 10 | 插件行为检测间隔（tick） |
| `magnetDefaultRange` | 5 | 磁吸 / 拾取插件的默认半径 |
| `autoCookingBatchSize` | 8 | 自动烹饪单次处理的最大物品数 |
| `enableAnvilCraftRecipes` | true | 是否启用本模组物品的铁砧工艺配方 |
| `debugLogging` | false | 在日志里打印插件派发信息，排查「插件不生效」时打开 |

## 八、兼容性与已知限制

- 面向 **Minecraft 1.21.1 / NeoForge**，与铁砧工艺 1.6.0 及以上搭配使用；
- **不使用 mixin**，不修改铁砧工艺本体代码；插件面板以叠加层形式绘制，因此不会关闭已打开的终端界面；
- 过滤插件只约束本附属的自动入库（磁吸拾取、烹饪产物、炼金产物等），玩家手动存进终端的物品不受它限制；
- 自动烹饪使用原版烹饪配方（熔炉 / 高炉 / 烟熏 / 营火）；铁砧工艺的多方块「超级加热」配方不适合在存储内套用；
- 炼金插件使用存储里**现成的药水**，喷溅药水就地投掷，不做弹道瞄准；
- 铁砧加工只收录纯物品进出的加工方式，需要炼药锅流水的配方（固液反应、快速烹饪）不收录；
- 压缩插件使用原版 3×3 合成配方，与铁砧工艺自身的「物品压缩」判定范围可能不完全一致。

## 九、常见问题

**Q：插件装了没反应？**
A：确认终端在身上（不是放在安装台里）；确认插件在列表里是「启用」状态；把配置里的 `debugLogging` 改成 `true`，日志里会有 `plugin-dispatch` / `plugin-run` 两行，缺哪一行就知道问题出在哪一环。

**Q：界面里的存储是空的 / 插件说存储不可达？**
A：本地终端要求 32 格内有大型板条箱；潜影终端要求身上有潜影集装箱；超维终端要求已绑定存储。

**Q：锻造为什么要放模板，会不会被吃掉？**
A：模板不可少（决定能锻造出什么），但**不会被消耗**，放一次可以一直用。

**Q：铁砧加工点「开始加工」没反应？**
A：检查存储里是否真有该配方需要的材料；过滤表留空表示不限制，但填了内容就只处理表里的物品；输入槽如果指定了物品，也会只处理那一种。

**Q：充能插件不工作？**
A：需要站在铁砧工艺的电网覆盖范围内（输电杆提供范围），并且电网功率没有过载。

## English Summary

**AnvilCraft-TerminalPlugins** (`anvilcraft_terminal_plugins`) is an addon for **AnvilCraft** on Minecraft 1.21.1 /
NeoForge that adds a **plugin (upgrade module) system** to the Local, Shulker and Hyperdimension terminals.

- **Plugin Station** — put a terminal and staged plugins in it, press "Install all"; up to 5 plugins per terminal.
- **Plugin panel** — an overlay drawn on the terminal screen (button or **K**); each plugin has a **settings** page and,
  for the ones that run recipes, a **run** page with input/output slots.
- **14 plugins** — filter, magnet/pickup, auto cooking, feeding, alchemy, fluid, tool swap, mob catcher, XP pump,
  smithing (tool / metal / template, the template is kept), void, compacting, charging (draws power from an AnvilCraft
  power grid) and anvil processing (manual, batch).
- **Recipes** — AnvilCraft-style only (stamping, time warp, the charger's charging recipe); no crafting table recipes.
- **Config** — `config/anvilcraft_terminal_plugins-common.toml` (`maxPluginsPerTerminal`, `pluginTickInterval`,
  `enableAnvilCraftRecipes`, `debugLogging`, ...).
- **License** — LGPL-3.0-or-later.
